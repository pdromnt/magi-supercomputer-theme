01 · Operating principles

Dense without becoming cryptic.

MAGI uses Amber's luminous terminal language for real interfaces. Hierarchy comes from type, tone, and disciplined borders—not mystery meat controls or empty decoration.

Readable

Contrast first

Bright neon identifies action and status. Muted copy still meets normal-text contrast targets.

Nominal

Operable

States are visible

Every interactive primitive defines hover, active, focus, disabled, invalid, and selected states.

Adaptable

Not app cosplay

The system provides semantic building blocks. Product-specific names and fictional chrome remain in the product.

Framework agnostic

02 · Color

A small palette with explicit jobs.

Use semantic roles in application code. Raw palette values exist to build those roles, not as a grab bag.
